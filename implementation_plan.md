# Implementation Plan: Model Context Protocol (MCP) Integration for AI Agents

## 1. Overview & Objectives
Connect **Plates** to Anthropic's **Model Context Protocol (MCP)**, turning Claude Desktop, Cursor, or any MCP-compatible AI into an intelligent personal trainer and nutrition assistant. Through MCP, the AI gains native tools to read past workout logs, evaluate progressive overload, log new sessions, create routines, and manage nutritional shopping lists.

## 4. MCP Tools & Resources Specification

### A. Workout Tools
1. `get_workout_history`:
   - **Parameters**: `limit` (number, default 10), `routineName` (optional string).
   - **Returns**: Formatted history entries with sets, reps, weights, duration, and calculated volume.
2. `log_completed_workout`:
   - **Parameters**: `routineName` (string), `exercises` (array of `{ name, sets: [{ weight, reps }] }`), `durationSeconds` (number).
   - **Action**: Writes workout entry to history; updates PR records; sends real-time confirmation.
3. `analyze_progressive_overload`:
   - **Parameters**: `exerciseName` (string), `timeframeWeeks` (number).
   - **Returns**: Historical volume trends, estimated 1RM progression, and suggested weight targets for next session.

### B. Routine Tools
1. `get_routines`:
   - **Returns**: List of all configured workout routines and exercise sequences.
2. `create_or_update_routine`:
   - **Parameters**: `name` (string), `exercises` (array of strings), `routineId` (optional).
   - **Action**: Saves customized splits (e.g. "Hypertrophy Push Day") directly into Plates.

### C. Shopping & Nutrition Tools
1. `get_shopping_list`:
   - **Parameters**: `category` (optional), `onlyUnchecked` (boolean).
   - **Returns**: Current grocery and supplement items.
2. `add_shopping_items`:
   - **Parameters**: `items` (array of `{ name: string, category: string, price?: number }`).
   - **Action**: Injects groceries generated by meal-planning prompts directly into the app.

### D. MCP Resources (Live Context)
- `plates://summary`: Real-time text summary of current weekly volume, streak, and recent PRs.
- `plates://routines/active`: Contextual details of any currently active workout session.

## 6. Implementation Steps
1. Initialize `mcp-server/` with `@modelcontextprotocol/sdk` and `zod`.
2. Implement file/sync storage adapter to bridge browser `localStorage` and server.
3. Write tool handlers with comprehensive Zod input validation schemas.
4. Build resource providers (`plates://summary`).
5. Compile and link with Claude Desktop config.
6. Verify round-trip commands in Claude ("What did I bench on my last workout?", "Add 5lbs to my squats next session").
